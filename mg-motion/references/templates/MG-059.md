# MG-059 · 白板层级树与拆分示意

状态：已自检，待最终验收。画幅固定 1920×1080，30fps；样片为无声视频。

## 参考与动作

原片 303，采用 220–238 秒。sample.mp4 按参考结构及中文转写制作；usage.mp4 展示参数更换后的独立内容。

白板灰色双框和托槽、手写标题与下划线；三条灰色层级线按顺序画出，蓝绿红层级标记随后出现，黑色树枝由上到下逐段绘制，笔尖跟随；叶节点落点，最后书写三行解释。

0–1.2秒标题与下划线；1.2–4.1秒层级虚线和标记；4.3–7.7秒逐段画14条树枝；7.7–8.5秒叶节点；8.8–11秒说明文字；余时完整停留。

## 参数与使用

durationSeconds 12–26；title≤24字宽；levels固定3项/每项≤3；summary 1–3行/每行≤24；leaves为空或8项/每项≤2；notes 0–3条/每条≤20；footnote≤54。

字数限制为中文宽度单位；ASCII字符通常按半角计。超出限制时 validateProps 会明确拒绝，不自动截断文案。复制 usage-params.json，替换需要的字段；durationSeconds 会同步修改合成总帧数与动画节奏。

运行时入口：src/batch/MG-059/entry.tsx。支持 MG-059-Reference 和 MG-059-Usage。已有 Remotion 4.0.534、React 19 的项目可使用：

```powershell
npx remotion render src/batch/MG-059/entry.tsx MG-059-Usage usage.mp4 --props=usage-params.json --codec=h264 --concurrency=1
```

source/ 内含 model.tsx、demo.ts、entry.tsx、common.tsx，辅助导入已改为本目录相对路径。独立使用时可把这四个文件一起放入项目，入口指向 source/entry.tsx。依赖 Remotion、React 和系统字体 Microsoft YaHei / KaiTi；更换字体后须复看中文边界。
