# 连续 MG 的动作与声音编排

连续 MG 要让对象的变化帮助观众理解内容。色彩与字体统一后，构图仍可以变化；同一对象也可以从局部进入全景、改变尺度或承担下一段的视觉联系。这里是制作判断依据，不是新的 CLI 模式，也不会自动给旧模板增加动作。

## 参考、能力与成片分开理解

完整样片保留为参考：观察它如何建立问题、安排重点、连接段落和结束。可以按功能段标注时间点，但保留片段前后的上下文，避免只学到一次漂亮的入场而丢失它服务的内容。

从参考中提炼可复用的方法，例如“同一输入分发给多个对象”“通过对齐建立比较”“放大局部后返回整体”。记录参与对象、前后状态、运动轨迹、触发条件和适用边界。颜色、示例文字、固定业务判断和原片的时长，不应随方法一起被默认继承。

制作新片时，从全片要讲清的内容出发，安排对象和状态如何接续，再寻找实现方式。完整模板是可选实现之一：它的表达关系、动作和视觉都适合时可以整体复用；只适合其中一部分时，在项目源码中提取或调整；没有合适能力时实现对应动作。不要先给每句文案分配一个模板，再试图用统一颜色补救它们之间的关系。

当前工具实际提供的是独立模板、参数、素材映射、story 信息布局和顺序组合。上述方法是设计和代码复用的依据，尚未构成通用的动作原语 API 或自动编排器。项目中成功实现一次的方法，需要进一步验证其他内容与边界后，才适合提取为共享组件。

## 从表达关系开始

把画面计划写成“对象在什么条件下发生什么变化，观众因此知道什么”。例如：

- **到期失效**：剩余积分先保持可用；时间线到达有效期边界后，积分失效，数值在该时点清零。不能用缓慢消耗或低于合格线代替这件事。
- **比较选择**：让相同条件下的对象并置、对齐或进入同一标尺，变化突出比较维度。不要为了制造运动而把比较对象轮流藏掉。
- **产能换算**：在有真实换算依据时，把额度转为可完成任务的份数；没有数据就演示“额度用于任务”的关系，不补造数量和结果。

示例只说明关系，不规定所有内容都要用硬币、时间线或某套版式。先找到能承载本段意思的图形，再决定如何画。

## 用同一套视觉语言推进

选定少量有职责的颜色、字体层级、轮廓与填充方式，并确定动作是克制、轻快还是有重量感。关键动作使用一致的加速、减速、落点与力度。主题切换时，保留足够的对象身份或空间联系，使观众知道新画面从哪里来。

构图由当前重点决定：大字适合建立问题，局部放大适合解释机制，并置适合比较，收束适合结论。它们可以在一套设计里衔接，不必都装进同样大小的卡片。画面上的文字承担命名、关键事实和结论；较长解释可以交给口播，或在无声版本中单独安排足够阅读空间。

为每个动作写清开始状态、触发事件、结束状态和可读的结果。优先沿对象本身的运动、变形、遮挡或构图变化衔接；内容密集时避免前后两组文字长时间淡叠。能保留的元素不反复播放同一套入场，改变意义的文字也不能未经处理突然替换。

## 时间由信息与动作共同决定

动作准备、发生、结果停留各有作用。重点动作可以快，重要结论需要读得完；安静的停留本身不是错误。查看实片时判断是否仍在建立理解：如果观众已经读完、主体也没有新变化，只剩装饰漂浮或进度条移动，就应缩短该段，或重新设计内容推进。

不要按固定秒数强制加动画，也不要把所有阶段平均分时。需要动的部分完成明确动作，需要读的部分保持稳定。转场的长度和力度应配合内容，不能为跟节拍而截掉因果过程或结论。

## 声音如何参与

- **有口播**：先测音频中的语义段、重音和停顿，再让画面动作对齐关键意思；保留必要的提前展示和结果阅读时间。没有真实音频时，标注时间为估算。
- **有 BGM**：可以先确定速度、情绪和主要乐句，把适合的动作落在节拍或乐句转折处。优先保留内容的完整性，不要求每拍都切镜头。音乐有助于整体节奏，不能让静态换字自动成为 MG。
- **有音效**：在到期、碰撞、锁定、转换等明确事件上少量使用，强弱对应动作的重要程度；避免每个字和每次入场都发声。
- **无声交付**：靠画面动作和短文字建立同样的因果关系。带声音的版本也做一次静音检查，确认核心信息不是只存在于声音里。

当前默认渲染命令不生成旁白、音乐或音效。用户需要声音时，使用其提供或明确可用的音频，在项目工程或后期剪辑中加入，并检查时长、音量和结尾；不要把计划中写了 BGM 当作已经完成音频制作。

## 试片检查

先看关键动作前后，再按正常速度看整段。检查观看顺序是否明确、动作是否表达原意、对象关系是否连续、重点是否有足够阅读时间；同时检查突兀的文字替换、淡叠重影和没有作用的停留。只有颜色一致、参数通过或播放器不掉帧，都不能证明美感与节奏已经合格。

对某个案例做的项目动画先保留在项目中；若要入库，再按 [扩充模板](expansion.md) 检查另一组内容的复用范围。不要将一个专用演示包装成所有文案都能直接使用的通用能力。
