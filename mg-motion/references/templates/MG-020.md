# MG-020 · Skill 调用

## 连续表达适配（v1.2）

- 每个 `stats` 条目支持 `numberMode: "metric" | "ordinal" | "static"`。缺省保持历史数字计数；真正的数量、比率才用 `metric`。
- 用 1、2、3 表示顺序时必须设 `numberMode: "ordinal"`，`value` 为正整数且 `decimals: 0`，数字始终直接显示，不从 0 增长。`static` 用于不需要计数动效的固定数值。
- 三个概念不等于三个统计指标；连续讲解优先用统一故事布局的 criteria，不要仅因条数相同就套数据卡。
- `footerLabel` 是可选单行页脚（最多40字），省略或空字符串不显示。复用版默认不再显示 `PRODUCT INSIGHTS`；参考版显式保留它。
- 本次仅检查源码、类型及参数行为，没有重新渲染样片；下方历史视觉检查描述不涵盖新增选项。

使用 `node scripts/mg.mjs inspect MG-020` 查看当前默认参数；`params MG-020 --out work/params.json` 导出后修改；`render MG-020 --params work/params.json --out outputs/video.mp4` 出片。当前已纳入 Skill 注册表。

## 调用和参数

stats 2～3项；label≤10字；value 0～1000000；decimals 0～1；suffix≤4字；title≤16、subtitle≤32字。

修改 reference-params.json 或 usage-params.json 后，可通过 Remotion 的 --props 参数调用对应入口。durationSeconds 会同步决定合成时长。源码在 source/，model.tsx 导出 Template 和 validateProps；demo.ts 保留两组示例。
