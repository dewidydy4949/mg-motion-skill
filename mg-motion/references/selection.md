# 从素材选择模板

先判断是独立片段还是连续讲解；连续讲解优先用 [story.md](story.md)。需要旧模板时，先确定整段视觉方案和镜头的表达关系，再筛选。无需让用户选择编号，也无需把50套源码和说明全部读入。

```text
node scripts/mg.mjs match "手机问答，突出最后回复" --duration 9
node scripts/mg.mjs match "录屏教程，鼠标点击并放大界面" --media video --duration 12
node scripts/mg.mjs match "年份时间线和人物成长" --media image --duration 12
node scripts/mg.mjs inspect MG-036
node scripts/mg.mjs match "大数字卡" --intent ordinal --duration 6
node scripts/mg.mjs match "阈值警报" --intent expiry --duration 7
```

`match` 默认返回最多3个候选。`--limit` 可设1–10。`--intent` 与 `--family` 是硬过滤，意图名称及模板限制在 `compatibility.json`。明确意图时也可找到未命中查询词的适用模板；关键词分数只用于候选排序，不代表置信度。第二个例子不会把阈值模板推荐给到期失效；没有旧模板支持时返回空候选，改用 story 或项目适配。

脚本不读取图片或视频，不自动推断句子中的真实逻辑。先由使用者概括表达关系；不要把“到期失效”谎报成“阈值”以通过筛选。没有命中时可以改善查询，但不能去掉必须的语义或素材条件来强套模板。

目前旧模板各自属于独立的 `legacy-mg-xxx` 风格族。这是保守地表示尚未认证为同一套设计，并非所有深色模板都能相互拼接。`--family` 筛选不会修改颜色、字体或版式。一个项目若要把多个模板适配成共同视觉，应在项目引擎中实际修改，并记录适配说明。

## 素材的用途

- **素材要出现在画面里**：检查返回的 `mediaSlots`，只向真实存在的槽填入资源。`--media` 仅返回支持通用 `asset:` 映射的模板；图片与视频分别筛选。`path` 中 `[]` 表示数组的每项。槽位定义为媒体对象时需要填写 `src`、`type` 等字段，具体形状看 `inspect`/使用卡/模型类型，不能把路径字符串直接填进整个对象。
- **素材只提供文字或数据**：例如从聊天截图整理问答，再用手机对话模板重建气泡；这种用法不要求模板能放截图。保留原意，必要的摘要或拆镜头应说明。不要暗中把真实录屏替换成代码示意图。
- **素材是想模仿的参考视频**：检查它的关键构图、运动顺序、节奏和信息容量，再比较候选。外观类似不能证明运动结构适合；模仿新结构时使用 expansion.md。

媒体槽的 `binding: asset` 可走 rendering.md 的资源映射。少数 `binding: public-relative` 槽只接受 public 内相对路径，不能把 `asset:` 自动解析后的绝对URL塞进去。需要这类槽时使用项目自己的引擎副本，在 public 中存放素材并按模型要求填相对路径；或者新增经过验证的适配。不要修改安装目录里其他项目的输入。

## 决定复用程度

| 情况 | 处理 |
| --- | --- |
| 信息结构、素材形状、内容容量都合适 | 只改参数和镜头时长 |
| 结构基本合适，需要小幅布局或动作变化 | 在项目副本中改对应组件，保留原模板编号/版本来源并检查变化 |
| 缺少关键素材能力，或运动/信息结构不同 | 选择其他模板，拆镜头，或按 expansion.md 新做模板 |

同时满足表达关系、全片视觉方案、素材槽、容量和时长要求后才选用。没有品牌规范时自行选择一套清晰的视觉方案，不增加确认步骤。

注意模板的固定含义：MG-020 默认是增长指标，步骤序号必须逐项声明 `numberMode: "ordinal"`；MG-022 只做阈值判断，不表示过期；MG-032 滚动词组不能自动建立因果关系；MG-047 的三路语义汇聚不等同于所有“三件事”。固定文案、默认背景和内部动作也属于复用边界，查看对应使用卡。能渲染不等于适用。

## 时长与后续修改

`duration.behavior` 用文字说明延长时长会增加停留、同比缩放动作，还是需要调整绝对时间点。它不保证任意内容都能放进该时长；最终以 `check` 和实际可读性为准。未知边界用 null 表示，不当作无限支持。

每个项目保存镜头计划、用户素材映射、模板版本及实际参数。已有 `.input.json` 可恢复输入，但单镜头参数位于其中的 `props`；含外部素材时保留同记录的 `assets` 映射，按 rendering.md 重跑。用户只改一句话时复用原镜头参数，不重新扫描整个库。

选择目录在 `selection.json`，完整出处/预览/卡片在 `catalog.json`。新增或改变模板能力时同步更新对应条目，保持所有模板编号一一对应。
