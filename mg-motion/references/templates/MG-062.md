# MG-062 · 顶部年份轴与里程碑票卡

状态：已自检，待最终验收。画幅固定 1920×1080，30fps；样片为无声视频。

## 参考与动作

原片 375，采用 33.4–38.5 秒。sample.mp4 按参考结构及中文转写制作；usage.mp4 展示参数更换后的独立内容。

浅色纸底，黄字黑描边大标题；票卡从左右交替飞入，轻微回弹旋转落位，左边彩色年份区与黑色打孔线，右边粗体名和手写说明，最后盖绿色统计印章。横屏用左标题与印章、右票卡排布。

0–0.3秒标题；0.7秒第一张票卡，之后每0.52秒一张；5秒绿色统计印章进入；余时停留。复用版可选顶部年份轴，定位点随票卡出现移动。

## 参数与使用

durationSeconds 6–20；titleLines 1–3行/每行≤8字宽；tickets 3–7项/年份1900–2100升序/name≤18/detail≤27；showAxis布尔值；stamp≤8；summaryValue≤11/summaryLabel≤20；footnote≤52。

字数限制为中文宽度单位；ASCII字符通常按半角计。超出限制时 validateProps 会明确拒绝，不自动截断文案。复制 usage-params.json，替换需要的字段；durationSeconds 会同步修改合成总帧数与动画节奏。

运行时入口：src/batch/MG-062/entry.tsx。支持 MG-062-Reference 和 MG-062-Usage。已有 Remotion 4.0.534、React 19 的项目可使用：

```powershell
npx remotion render src/batch/MG-062/entry.tsx MG-062-Usage usage.mp4 --props=usage-params.json --codec=h264 --concurrency=1
```

source/ 内含 model.tsx、demo.ts、entry.tsx、common.tsx，辅助导入已改为本目录相对路径。独立使用时可把这四个文件一起放入项目，入口指向 source/entry.tsx。依赖 Remotion、React 和系统字体 Microsoft YaHei / KaiTi；更换字体后须复看中文边界。

## 限制

- 原片竖版，横版采用左标题/右列表；没有复制场馆建筑、人物海报或品牌素材。
- 参考版数字直接取自原片且未核实；不作为市场事实发布。
- 运行时副本缺少 library/index.json，因此 npm run check 的索引检查无法执行；TypeScript 单独通过。总库索引由主任务集成后检查。
