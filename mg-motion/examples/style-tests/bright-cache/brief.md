# 亮色几何：把常用内容留在手边

文案：常用的内容，先留一份在手边。下次需要时直接取；发现版本变了，再更新这份副本。

12 秒，1920×1080，30 fps，无声。无真实口播，动作时点按文意估算。这是缓存的概念示意，未描述具体系统的失效策略，也不伪造性能数据。

主参考 MG-060：实际查看静态预览、阅读使用卡和源码，借鉴蓝/粉/黄有限套色、暖纸底和印刷颗粒，以及对象保持身份的连续运动。辅助 MG-050：查看预览与源码，借鉴几何单元展开、复制、由图形动作推进关系。没有观看原始视频或重渲染参考片；不复用滑杆控制量、六边形结构的语义。

用一个远处内容源、一个近处缓存托盘和取用手形持续在场。源内容复制并沿长弧线进入托盘；再次取用沿短弧线，副本仍留在托盘。源版本变化被标注后，新版沿同一路径替换旧副本。大标题只提示当前意思，主要关系由对象与路径变化表达。

修改画面与时间点：src/Cache.tsx。无额外依赖、外部素材或品牌资产。系统中文字体为 Microsoft YaHei，备用 Noto Sans SC；跨设备需检查字宽。运行使用 mg-motion/scripts/project.mjs。实际检查记录由项目外的 review.json 与 review.jpg 记录。
