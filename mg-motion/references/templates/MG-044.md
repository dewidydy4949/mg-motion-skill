# MG-044 · 日历排程与内容发布卡

## 用途与参考

适合展示AI工作流排程、连续任务和一周内容计划，日期、标签、任务卡可参数化。

参考来源：301 / bizibeast，截取 22–25.8 秒。原文件：`301-bizibeast-bento-surf-dynamic-40-second-motion-graphics-video-on.mp4`。源片中的示例文字按画面翻译用于参考样片；案例信息来自原片，未作外部核实。

## 运动拆解

- 0-0.8 标题和周历入场
- 0.8-2.2 彩色便签从上方依次掉落
- 2.2-3.0 选中卡片描边突出
- 3.0-4.3 平台卡出现、蓝线描出
- 4.3之后 黄色点沿连接移动、显示已排程

## 输入与可调范围

durationSeconds 6–20秒；title≤23字宽、complete≤12；days恰好7项、每项≤4。tasks 3–7项、每天最多一项；day为0–6整数、slot为0–2整数；普通label≤7字宽、选中label≤10、time≤5；selected为有效任务索引。channels 2–4项、name≤7、short≤2；颜色均#RRGGBB。

字数限制按中文显示宽度计算：汉字及非拉丁字符约1格，普通拉丁字符约0.58格；不接受空白字符串或换行。最终布局使用代码中的中文字体优先列表，建议安装 Noto Sans SC / Noto Serif SC，Windows 可回落微软雅黑/宋体。内容过长时请缩短或分成下一镜头。

## 使用

- `reference-params.json`：参考结构样片输入，时长 7.5 秒。
- `usage-params.json`：改变正文/任务/数量等内容的调用示例，时长 9 秒。
- `source/model.tsx` 导出 `Template`、`validateProps` 和 `Props`；`demo.ts` 导出两套默认参数。
- `entry.tsx` 注册 `MG-044-Reference`、`MG-044-Usage`。`--props` 覆盖默认输入，时长随 `durationSeconds` 计算。

在已安装 React 19 和 Remotion 4.0.534 的工程中，保留 `source/lib/common.tsx` 相对目录，执行：

```powershell
npx remotion render source/entry.tsx MG-044-Usage render.mp4 --props usage-params.json --codec=h264 --concurrency=1
```

`sample.mp4` / `usage.mp4` 为两套完整视频；`poster.jpg` 为参考样片关键画面；`comparison.jpg` 为原片与重写版对照；`sheet.jpg` / `usage-sheet.jpg` 为12点时序图；`sample-last.jpg` / `usage-last.jpg` 为完整末帧。无音轨，配音与音乐请在剪辑阶段另配。
