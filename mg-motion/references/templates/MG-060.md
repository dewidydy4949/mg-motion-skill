# MG-060 · 套色关系图与控制滑杆

状态：已自检，待最终验收。画幅固定 1920×1080，30fps；样片为无声视频。

## 参考与动作

原片 362，采用 39.65–43.5 秒。sample.mp4 按参考结构及中文转写制作；usage.mp4 展示参数更换后的独立内容。

暖灰纸底与印刷散点；蓝色粗标题、蓝色竖轨道和标签、桃红圆角滑块、黄色底端细线。滑块在多个控制点之间连续变速，位置与显示值同步。

前6%淡入；8%–84%各滑杆沿输入值序列连续移动；最后16%停在最终值，便于读数。原片39.65–43.5秒确有连续滑杆运动。

## 参数与使用

durationSeconds 4–15；title≤15字宽；sliders 2–5项/label≤6；每项values为3–6个0–100数值；showValues布尔值；note为空或≤40字宽。

字数限制为中文宽度单位；ASCII字符通常按半角计。超出限制时 validateProps 会明确拒绝，不自动截断文案。复制 usage-params.json，替换需要的字段；durationSeconds 会同步修改合成总帧数与动画节奏。

运行时入口：src/batch/MG-060/entry.tsx。支持 MG-060-Reference 和 MG-060-Usage。已有 Remotion 4.0.534、React 19 的项目可使用：

```powershell
npx remotion render src/batch/MG-060/entry.tsx MG-060-Usage usage.mp4 --props=usage-params.json --codec=h264 --concurrency=1
```

source/ 内含 model.tsx、demo.ts、entry.tsx、common.tsx，辅助导入已改为本目录相对路径。独立使用时可把这四个文件一起放入项目，入口指向 source/entry.tsx。依赖 Remotion、React 和系统字体 Microsoft YaHei / KaiTi；更换字体后须复看中文边界。
