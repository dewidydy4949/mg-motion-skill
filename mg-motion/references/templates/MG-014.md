## 改哪些参数

`source/model.tsx` 定义组件；`source/demo.ts` 内有两套真实演示参数；`source/entry.tsx` 注册 `P02-Reference` 和 `P02-Usage`。

| 参数 | 用途与边界 |
|---|---|
| `columns` | 4～7 列；每列有唯一 `id`、短 `label`、`width` 权重，可选图标、左右对齐和锁标记。 |
| `rows` | 3～6 行；唯一 `id`；`cells` 按列 id 填值，支持纯文字或 `{text, tag}` 标签。 |
| `focus` | 1～2 个有效且相邻的列 id。双列先圈住第一列，再扩展到第二列；单列提问取靠左的焦点列。 |
| `title` / `viewLabel` | 开头表名和视图名称。 |
| `question` | 单列旁的提问；用 `\n` 分行，最多 3 行，每行约 10 个汉字宽度。 |
| `closing` | 返回整表时显示的结论短句。 |
| `footnote` | 数据说明，建议明确来源或示例性质。 |
| `durationSeconds` | 8～12 秒，内部阶段按比例调整；本轮只渲染验证了 10 秒。 |
| `dimOpacity` | 非重点列的透明度，0.12～0.5，默认 0.22。 |

列宽权重限 150～440，按整表 1680 像素宽归一化后，每列需在 150～600 像素内。标题、单元格、列数、行数或焦点不合适会提示具体问题；不静默删掉内容。字号估算用于短文字，不能当作任意长文的自动排版工具。

图标为本组件自绘 SVG，未复用原视频品牌或头像。字体使用系统 Arial / Noto Sans SC / 微软雅黑，换机器需重新检查中文字体与画面。
